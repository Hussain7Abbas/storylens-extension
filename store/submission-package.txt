=== REVIEW NOTES (optional field in dashboard) ===

StoryLens enhances web novel reading with keyword highlights, aliases, chapter notes, text replacements, and optional user-requested AI tools. Shared reference data syncs with https://storylens-api.iscoded.com. Test reading features by opening a supported chapter, clicking the toolbar icon, and adding a colored keyword. For Summarize, separately install Story Lens Client, sign in to Claude Code or Codex CLI, pair the token in the popup, choose a model, and click Summarize on an HTTP(S) page. User-requested AI chapter-selector detection sends the page URL and HTML through the Story Lens API to OpenRouter. If configured, usage events go to Google Analytics unless turned off in Settings → General; a supported-page event includes the site's hostname. See the English and Arabic privacy policies for details.
