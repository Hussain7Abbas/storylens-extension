=== CHROME WEB STORE — PRIVACY PRACTICES ANSWERS ===

Does your extension collect or transmit user data?
Yes

Data types to declare

[YES] Website content
Reason: The Extension reads visible chapter text on novel pages the user visits so it can apply keyword highlights and text replacements configured by the user.

[YES] User activity
Reason: The Extension stores and syncs user-created glossary activity such as novels, keywords, categories, replacements, and related settings through the StoryLens API.

[NO] Personally identifiable information
Reason: The current public Extension version does not require user login and does not intentionally collect names, email addresses, or similar identity data.

[NO] Health information
[NO] Financial and payment information
[NO] Authentication information
[NO] Personal communications
[NO] Location
[NO] Web history

Certifications / usage statements

Is the data encrypted in transit?
Yes — data is transmitted to https://storylens-api.iscoded.com over HTTPS.

Is the data sold to third parties?
No

Is the data used for purposes unrelated to the item's core functionality?
No — data is used only to provide novel glossary highlighting and syncing.

Is the data transferred to third parties?
No — aside from operating the StoryLens backend needed to provide the service.

Is collection required for the Extension to work?
Partially optional:
• Using the Extension locally on a page requires reading that page's visible chapter content
• Syncing and saving glossary data requires transmission to the StoryLens API
